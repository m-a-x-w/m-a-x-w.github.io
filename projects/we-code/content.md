### Purpose:

The purpose of this project was to create a website that would adapt it's content and lessons based on the users interests. By changing a lesson to explain using terms from the interest, or something related to the interest, the user would be more attentive. As a result of that, they would learn the content more efficiently, and would be more inclined on coming back to keep learning.
