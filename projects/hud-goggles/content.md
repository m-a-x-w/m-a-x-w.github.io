### Purpose:

The purpose of this project was to create a device to help people with hearing issues be more aware of their environment. By using machine learning and audio processing, the system helps users identify and locate important sounds in their surroundings, enhancing their spatial awareness and safety.

### Technical:

- **Sound Detection**: Utilized an audio tagging model for real-time audio classification, optimized to run more efficiently on embedded systems to detect various important sounds (sirens, alarms, and vehicle horns).

- **Visual Interface**: Created a heads-up display (HUD) system using a transparent OLED display mounted on glasses frames, showing directional arrows and sound type indicators in the user's field of view.

- **Embedded System**: Built on a Raspberry Pi 4 with custom 3D-printed case design that integrates with the glasses frame. The case houses the main board, battery system, and multiple microphone array while maintaining a comfortable form factor that is able to be worn.

### Implementation Details:

- **Ergonomic Integration**: The 3D-printed case was specifically designed to distribute weight evenly across the glasses frame, with the heavier components (battery, Raspberry Pi 4) positioned towards the back for better balance.

- **Thermal Management**: Incorporated ventilation channels in the case design to manage the heat generated by the Raspberry Pi 4 during continuous operation.

- **Modular Design**: The case features a modular design allowing easy access to components for maintenance and upgrades. The microphone array is mounted in detachable pods on the frame of the glasses that can be adjusted for optimal sound detection.

### Results:

The project won honorable mention at TJHSST Science Fair, demonstrating:
- 94% accuracy in sound classification
- Direction detection within 1-2 seconds
- Successful siren detection with directional indication
- Comfortable wearability for extended periods
